=========================================================
ThisWorkbook に追加するコード
=========================================================

VBAエディタの「ThisWorkbook」モジュールに以下を貼り付けてください:

---------------------------------------------------------
Private Sub Workbook_Open()
    modChartFormatter.AddChartContextMenu
End Sub

Private Sub Workbook_BeforeClose(Cancel As Boolean)
    modChartFormatter.RemoveChartContextMenu
End Sub
---------------------------------------------------------

=========================================================
初回セットアップ手順
=========================================================

1. Excel を開き Alt+F11 でVBAエディタを起動

2. メニュー「ファイル」→「ファイルのインポート」で以下を順にインポート:
   - modChartFormatter.bas
   - frmChartFormatter.frm

3. 左側ツリーの「ThisWorkbook」をダブルクリックして
   上記のコードを貼り付ける

4. イミディエイトウィンドウ（Ctrl+G）に以下を入力して Enter:
   modChartFormatter.AddChartContextMenu

5. Excelに戻り、グラフをクリックして選択

6. グラフ上で右クリック → 「グラフ書式設定(F)...」を選択

=========================================================
使い方
=========================================================

「軸ラベル」タブ:
  - X軸・Y軸それぞれのタイトルテキストを入力
  - チェックを入れると表示、外すと非表示

「グラフサイズ」タブ:
  - 幅・高さをcmまたはポイントで指定
  - 「現在の設定を読込」で現在のサイズを確認できる

「文字設定」タブ:
  - フォント名・サイズ・太字・斜体を設定
  - 適用対象を選択（グラフエリア全体推奨）

「枠線設定」タブ:
  - 外枠（グラフエリア全体）の線種・線幅・色を設定
  - グラフ枠（プロットエリア）の線種・線幅・色を設定

「現在の設定を読込」ボタン:
  - 選択中グラフの現在の設定値をフォームに読み込む

「適用」ボタン:
  - 設定を選択中グラフに反映する

=========================================================
注意事項
=========================================================

・グラフを選択した状態で「適用」を押してください
・フォームを開いたまま複数のグラフに順番に適用できます
・グラフシートのサイズは変更できません（埋め込みグラフのみ）
・ファイルを開くたびに右クリックメニューが自動追加されます
  （ThisWorkbook の Workbook_Open に追加した場合）
