=========================================================
セットアップ手順（ReadMe）
=========================================================

【重要】以前の frmChartFormatter.frm はインポート不要です。
フォームは RunSetup マクロが自動生成します。

=========================================================
インポートするファイル（3つ）
=========================================================

  modChartFormatter.bas  ← グラフ操作ロジック
  modFormLogic.bas       ← フォームの動作ロジック
  modSetup.bas           ← フォーム自動生成・初期設定

=========================================================
インストール手順
=========================================================

1. Alt+F11 でVBAエディタを開く

2. 以下の設定を有効にする（初回のみ）
   「ファイル」→「オプション」→「セキュリティセンター」
   →「セキュリティセンターの設定」→「マクロの設定」
   →「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」にチェック

3. VBAエディタで「ファイル」→「ファイルのインポート」を3回実行:
   - modChartFormatter.bas
   - modFormLogic.bas
   - modSetup.bas

4. Alt+F8 → 「RunSetup」を選択して「実行」
   ※ フォームが自動生成され、右クリックメニューが追加されます

5. Excelに戻り、グラフをクリックして選択

6. グラフ上で右クリック → 「グラフ書式設定(F)...」を選択

=========================================================
ブックを開くたびに右クリックメニューを表示するには
=========================================================

VBAエディタの「ThisWorkbook」モジュールに以下を追加:

---------------------------------------------------------
Private Sub Workbook_Open()
    modChartFormatter.AddChartContextMenu
End Sub

Private Sub Workbook_BeforeClose(Cancel As Boolean)
    modChartFormatter.RemoveChartContextMenu
End Sub
---------------------------------------------------------

=========================================================
機能一覧
=========================================================

「軸ラベル」タブ
  - X軸（横軸）・Y軸（縦軸）のタイトルを入力
  - チェックON=表示、OFF=非表示

「グラフサイズ」タブ
  - 幅・高さを cm または ポイントで指定
  - 「現在の設定を読込」で現在サイズを確認

「文字設定」タブ
  - フォント名・サイズ・太字・斜体を設定
  - プレビュー表示あり
  - 適用対象: グラフエリア全体/タイトル/軸ラベル/凡例

「枠線設定」タブ
  - 外枠（グラフエリア）と グラフ枠（プロットエリア）を個別設定
  - 線種: 実線/破線/点線/一点鎖線
  - 線幅: 0.25〜3pt
  - 色: 10色（カラープレビューあり）

「現在の設定を読込」ボタン
  - 選択中グラフの設定値を読み込む

「適用」ボタン
  - 設定を選択中グラフに反映する

=========================================================
注意事項
=========================================================

・「適用」を押す前にグラフを選択してください
・フォームを開いたまま複数グラフに順番に適用できます
・グラフシートのサイズ変更はできません（埋め込みグラフのみ）
