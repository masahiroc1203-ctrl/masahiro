## 1. 最初に測るもの（実測チェックリスト）

設計値のうち推定・仮定のものを、作る前に実物で確定させる。測った値は §6 の記録表に書く。

| # | 測るもの | 道具 | 方法 | 反映先 |
|---|---|---|---|---|
| M1 | ボール径・ピッチ・芯ひも径 | ノギス | ピッチは「ボール 11 個の端から端 − 玉径」÷ 10 | `ball_d` `pitch` `cord_d` |
| M2 | チェーンジョイントの外径・長さ | ノギス | 長さがボール何個分か（ピッチ何個分か）を見る | `joint_d` `joint_span` |
| M3 | 取付面からチェーン 2 本の中心まで | 定規 | 取付板を当てる面（壁・窓枠の正面）から測る | `y_c` |
| M4 | ヘッド下端の床からの高さ | メジャー | ユニットの高さ = ヘッド下端 − S（S ≥ L/2 + 0.1 m） | 設置位置 |
| M5 | **上げ方向の最大チェーン力 F_up** | 吊りはかり（〜5 kg） | 全閉にして、手前（上げ側）のチェーンにはかりを掛け、真下へゆっくり一定速度で引く。動き出しから 10 cm までの最大値。3 回の平均 | `--f-up` |
| M6 | 下げ方向のチェーン力 F_down | 吊りはかり | 全開にして、奥（下げ側）のチェーンで同様に | `--f-down` |
| M7 | **全行程のチェーン移動量 L** | メジャー・テープ | 全閉→全開まで、チェーンの手が届く位置に 50 cm ごとにテープで印を付けながら引き、印の数で数える | `--travel` |
| M8 | STS3215 ホーン外径・ねじ穴ピッチ円・ねじ径・数 | ノギス | 付属のメタルホーン | `horn_d` `horn_bolt_pcd` `horn_bolt_d` `horn_bolt_n` |
| M9 | 出力軸中心から近い側のケース端まで | ノギス | | `srv_e` |
| M10 | ケース上面からホーン上面まで | ノギス | ホーンを付けた状態で | `horn_stack` |

測り終えたら再計算する：

```bash
python3 calc/winder_calc.py --f-up 22.0 --f-down 6.0 --travel 1.85
```

設計トルクがストールの 25% を超えたら歯数を下げる（[mechanical_design.md](mechanical_design.md) §2.2）。
CAD は `cad/winder.scad` 冒頭の `[要実測]` の値を書き換えて STL を出し直す。

## 3. 電源・配線

### A 案（推奨）

```
AC アダプタ 7.5V 3A ──DCジャック──▶ Servo Driver with ESP32 ──3ピン──▶ STS3215（ID = 1）
                                     （ESP32 の電源は基板上で作られる）
```

### B 案（ESP32 開発ボードを使う場合）

```
AC アダプタ 7.5V 3A ─┬─▶ バスサーボアダプタ V+ ──▶ STS3215
                      │      └ 1000µF/16V を V+–GND 間に
                      └─▶ 降圧モジュール（5V 出力）──▶ ESP32 の 5V 端子
ESP32 TX/RX ──▶ バスサーボアダプタ（UART → 半二重サーボバス）
GND はすべて共通
```

- STS3215 の定格は 7.4 V。7.5 V アダプタはこの範囲で使える（Gemini で検討した電源案のとおり）
- 起動時やロック時の電流で ESP32 がリセットする場合は、コンデンサを足すか、アダプタを 4 A 品にする

## 4. 組立

1. **サーボの初期設定**：ID = 1、ボーレートは既定（1 Mbps）。この段階で速度モード（Mode 1）で回ることを確認しておく
2. 付属メタルホーンを出力軸に取り付け、中心ねじで固定する
3. サーボをハウジングのスリーブに**後ろから**差し込む（出力軸が手前側の端、ケース上面が背面壁側）。後端キャップを M3 タッピング 2 本で留める。配線はキャップの窓から出す
4. スプロケットを、カバー側から背面壁の穴（φ25）に通してホーンに当て、M2×10 を 4 本締める（座ぐり側から）
5. 手でスプロケットを回し、ガード・背面壁に擦らないことを確認する
6. 設置する（[mechanical_design.md](mechanical_design.md) §5）。チェーンジョイントを合わせマークの逃げ溝に入れてからカバーを閉める

## 5. 試験

| # | 試験 | 合格基準（目安） |
|---|---|---|
| T1 | チェーンなしで Mode 1 運転（±2290 step/s） | 回転が安定。無負荷電流・温度を記録（基準値にする） |
| T2 | チェーンを掛け、トルク OFF のままチェーンを手で引いて 1 往復 | ジョイントが逃げ溝に入って引っかからない。歯飛びしない |
| T3 | 全行程の上げ・下げ（Mode 1） | 上げ 60 秒以内。最大電流を記録。5 往復連続で温度 60℃ 以下 |
| T4 | 原点出し（Mode 2、デューティ 35%） | 上限で 300 ms 以内に停止。ロック時の力をはかりで測り 50 N 以下 |
| T5 | 挟み込み：運転中に吊りはかりでチェーンを止める | 止まるまでの最大値を記録し、電流しきい値（T3 の最大電流 × 1.5）を調整 |
| T6 | アシスト：待機中にチェーンを 5 mm 引く／運転中に手で止める | 引けば動き出し、手で止めれば止まる。窓の開閉や風で勝手に動かない |
| T7 | 電源を切って入れ直す／切っている間に手で動かす | 前者は保存位置で再開。後者は原点出しが要求される |
| T8 | 停電時の手動操作 | カバーを外してチェーンを外せる。外さずに手で引いたときの力も記録 |

T4 の開ループ PWM（Mode 2）は、デューティの書き込み方（どのレジスタに書くか）をライブラリと実機で確かめてから行う。
