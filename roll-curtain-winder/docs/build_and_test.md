## 3. 電源・配線

```
AC アダプタ 7.5V 3A ──▶ Servo Driver with ESP32 ──3ピン──▶ STS3215（ID = 1）
                              │
                              ├─ 5V ──▶ ホール IC ×2（VCC）
                              ├─ GND ─▶ ホール IC ×2（GND）
                              └─ GPIO ◀─ ホール IC 出力（3.3V へ 10kΩ プルアップ、磁石が来ると LOW）
```

- B 案では、7.5 V から降圧した 5 V を ESP32 とホール IC に使う。GND はすべて共通
- ホール IC の線はセンサー台の下から出し、サーボの配線と一緒に制御基板まで引く

## 4. 組立・設置

1. サーボを初期設定する（ID = 1、Mode 1 で回ることを確認）
2. ホーンを付けたサーボをスリーブに後ろから差し込み、後端キャップで留める
3. スプロケットを背面壁の穴に通してホーンに M2 × 10 で固定する
4. ホール IC をセンサー台のポケットに下から差し込む（平らな面＝検出面をストッパー側に向ける）。接着剤で固定
5. ユニットをヘッドのすぐ下（ユニット上面とヘッド下面の間 約 30 mm）に、スプロケットが 2 本のチェーンの真ん中に来るよう取り付ける
6. チェーンを通す：カバーを外した状態で、2 本をスプロケットの左右の通路に入れる
7. ローラーを付ける：M3 × 16 をカバーの穴に通し、内側で MR63ZZ を通す。ローラーでチェーンをスプロケットに押し付けながらカバーをかぶせ、軸を背面壁にねじ込む。残りのカバーねじ 3 本を締める
8. ストッパーを付ける
   - **上限**：手で全開まで巻き上げ、ウエイトバーがヘッドに当たる 5〜10 mm 手前まで少し下ろす。奥のチェーンのユニット直下にストッパーをはさんで締める
   - **下限**：全閉まで下ろし、手前のチェーンのユニット直下に同様に付ける
   - 磁石は S 極を外向きにして、ストッパーの両側面に入れる

## 5. 試験

| # | 試験 | 合格基準（目安） |
|---|---|---|
| **T0** | **逆駆動トルクの測定**（最初に行う）：サーボ単体にスプロケットを付け、トルク OFF でポケットに掛けたひもを吊りはかりで引く。T_bd = 力 × 13.5 mm | 記録して `--t-bd` で手で引く力を計算。全閉からの上げ始めが 35 N を超えるなら C046 を検討 |
| T1 | チェーンなしで Mode 1 運転 | 回転が安定。無負荷電流・温度を記録 |
| T2 | 取付後、トルク OFF で手で全行程を上げ下げ | 全閉からの上げ始めの力を吊りはかりで記録。引っかかり・歯飛び・チェーンの巻き込みがない |
| T3 | モーターで全行程の上げ・下げ | 上げ 60 秒以内。最大電流を記録。5 往復連続で温度 60℃ 以下 |
| T4 | 原位置の検出（モーター・手の両方） | ストッパーが当たる位置でホール IC が反応し、5 回の繰り返しで位置のずれが ±1 mm 以内 |
| T5 | 止める力：ストッパーに当たったとき／運転中にはかりでチェーンを止めたとき | 止まるまでの最大値を記録し、電流のしきい値を決める |
| T6 | 電源を切って入れ直す／切っている間に手で動かす | 前者は位置を保持。後者は次の巻き上げきりで原位置を取り直す |
| T7 | 長時間運転（100 往復） | ボールの抜け・ポケットの摩耗・ローラーの異音がない |
| T8 | カバーを外してチェーンを抜く | 工具 1 本で 5 分以内に既製品の状態に戻せる |
