# 12週プログラム（週1回・20分）

キュボロ教室の進め方（制約付き課題 → 個人の試行錯誤 → 相互鑑賞）を家庭用にしたもの。
1回20分。飽きる前に終わらせるのが続くコツ。カード番号は [`課題カード.md`](課題カード.md) に対応。

## 進め方

各回の流れは3つ。

1. **お題を1つ渡す**（1分）— カードを読み上げる。制約は必ず1つだけ
2. **黙って見る**（15分）— 完成前に手も口も出さない。止まったときだけ「どこまでは転がった？」
3. **一緒に見る**（4分）— 写真を撮る。「この道、思いつかなかった」

## つまずいたら

- **手が止まる** → レベルを1つ戻す。制約が2つ以上になっていないか確認
- **転がらないまま諦める** → 親が「1個だけ」直して見せる。全部直さない
- **同じコースばかり作る** → 位置指定（1-6）か数指定（3-1）を足す。作風は否定しない
- **そもそも触らない** → 課題を出すのをやめて数週間おく。出しっぱなしにしておくのが一番効く
