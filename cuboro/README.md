# キュボロ 課題カード集

キュボロ（cuboro）を子どもと遊ぶための、制約付き課題カード32枚とカリキュラム。
スイス・ロシアの小学校で行われているキュボロ授業の進め方（制約付き課題 → 個人の試行錯誤 → 相互鑑賞）を家庭用に落とし込んだもの。

## ファイル

| ファイル | 内容 |
|---|---|
| [`課題カード.md`](課題カード.md) | カード32枚の全文（レベル0〜5） |
| [`print/cards.html`](print/cards.html) | 印刷用。A4に6枚ずつ、切り取って使う |
| [`12週プログラム.md`](12週プログラム.md) | 週1回20分・12週の進行表 |

印刷は `print/cards.html` をブラウザで開いて Ctrl/⌘+P。厚紙かカードスリーブに入れると持ちが良い。

## 大原則

1. **最初の数ヶ月は課題を出さない。** キュボロは積み木であってパズル教材ではない。いきなり課題を出すと失敗体験になる。
2. **順番は「親が作って見せる → 真似する → 自由に作る → 課題」。** レベル0はこの導入部分。
3. **制約は1回に1つだけ。** 2つ以上足すと途端に手が止まる。
4. **1回20分で切り上げる。** 飽きる前に終わる。出しっぱなしにして気が向いたら触れる状態が一番効く。

## 年齢の目安

| 年齢 | 使うレベル | 親の関わり方 |
|---|---|---|
| 3〜4歳 | レベル0のみ | ほぼ親が作る。転がす楽しさだけでいい |
| 5〜6歳 | レベル0〜2 | 「ここまでは合ってる」と部分肯定する |
| 小1〜2 | レベル2〜3 | 課題を出し始める。図に描かせる |
| 小3〜 | レベル3〜5 | 口を出さない。競争相手になる |

メーカー推奨は5歳から。立体構成の面白さが効いてくるのは5〜6歳以降で、それ以前は「積み木＋ビー玉」として遊ばせる。

## 声かけ

- 止まったとき → **「どこまでは転がった？」**（原因の切り分けを教えている）
- 詰まったとき → 「1個だけ動かすなら、どれ動かす？」
- できたとき → 「すごい」より **「この道、思いつかなかった」**（結果でなく発想を褒める）

避けたいこと:

- 「ちゃんと最後まで転がるように作りなさい」（制約が曖昧で、難易度が無限になる）
- 完成前に「そこ違うよ」と直す（自分で気づく機会を奪う）
- 見本の完コピを続けさせる（導入としては有効だが、続けると自分で考えなくなる）
