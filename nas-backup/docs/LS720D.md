# バッファロー LinkStation LS720D で使う

LS720D シリーズ（LS720D / LS720D/N）にスマホの写真・動画をバックアップするための手順です。

## 構成

LS720D には Docker やアプリを追加する機能がないため、**このアプリ（サーバー）は家の別の機器で動かし、LS720D の共有フォルダへ SMB（Windows のファイル共有と同じしくみ）で保存します。**

```
 スマホ ──Wi-Fi──▶ Raspberry Pi / Windows PC ──LAN (SMB)──▶ LS720D
 (ブラウザ)          nas-backup が動く                      共有フォルダ\SmartphoneBackup
```

サーバーを動かす機器は、次のどちらかを選んでください。

| 機器 | 向いている使い方 | 手順 |
| --- | --- | --- |
| **Raspberry Pi**（おすすめ） | つけっぱなしにして、いつでもスマホからバックアップしたい（消費電力は数W） | [2-A](#2-a-raspberry-pi-で動かす) |
| **Windows PC** | バックアップするときだけ PC をつければよい | [2-B](#2-b-windows-pc-で動かす) |

> Raspberry Pi は 4 / 5 がおすすめです（有線 LAN が 1Gbps）。3 でも動きますが、LAN が 100Mbps なので動画の送信に時間がかかります。

## 1. LS720D 側の準備

設定画面のメニュー名はファームウェアのバージョンによって多少異なることがあります。

1. **IP アドレスを確認する**
   PC の「NAS Navigator2」で LS720D の IP アドレスを確認します（例: `192.168.1.50`）。
   IP アドレスが変わると接続できなくなるので、LS720D の設定画面で IP アドレスを固定するか、ルーターで同じ IP アドレスが割り当たるように設定しておくと安心です。

2. **保存先の共有フォルダを決める**
   最初からある共有フォルダ `share` を使うか、設定画面の「共有フォルダー」で新しく作ります（例: `photo`）。

3. **（おすすめ）バックアップ用のユーザーを作る**
   設定画面でユーザー（例: `backup`）とパスワードを作り、2 の共有フォルダに「読み書き」できるようアクセス制限を設定します。
   ゲスト（ユーザー名なし）での接続は、Windows 11 などでは安全のためブロックされることがあります。

4. **保存先フォルダを作る**
   PC のエクスプローラーのアドレス欄に `\\192.168.1.50\share` と入力して開き、`SmartphoneBackup` フォルダを作ります。
   （Mac は Finder の「サーバへ接続」で `smb://192.168.1.50/share`）

   > このフォルダが無いとアプリは起動しません。LS720D の電源が切れているときなどに、間違って別の場所へ保存してしまわないための安全策です。

5. **スリープ設定を確認する**
   LS720D の省電力（スリープ）スケジュールを設定している場合、スリープ中はバックアップできません。

## 2-A. Raspberry Pi で動かす

Raspberry Pi OS（64bit / Lite でも可）が入っていて、LAN につながっている前提です。

### 1) Docker を入れる（初回のみ）

```sh
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# いったんログアウトしてログインし直す
```

### 2) アプリを置いて設定する

```sh
git clone https://github.com/masahiroc1203-ctrl/masahiro.git
cd masahiro/nas-backup/deploy/ls720d
cp .env.example .env
nano .env
```

`.env` の次の項目を書き換えます。

```ini
NAS_IP=192.168.1.50                 # LS720D の IP アドレス
NAS_SHARE=share/SmartphoneBackup     # 共有フォルダ名/1-4 で作ったフォルダ
NAS_USER=backup                     # LS720D のユーザー名（アクセス制限なしなら空）
NAS_PASSWORD=パスワード
```

パスワードを書いたファイルなので、ほかの人が読めないようにしておきます。

```sh
chmod 600 .env
```

### 3) 起動する

```sh
docker compose up -d --build
docker compose logs -f      # 動作ログを見る（Ctrl+C で抜ける）
```

`nas-backup 1.0.0` と表示されれば起動しています。Raspberry Pi の電源を入れ直しても自動で起動します。

### 4) スマホで開く

Raspberry Pi の IP アドレスを調べて、スマホのブラウザで `http://<Raspberry PiのIP>:8080` を開きます。

```sh
hostname -I     # 先頭に表示されるのが IP アドレス（例: 192.168.1.30）
```

### 更新・停止

```sh
git pull && docker compose up -d --build   # アプリを最新にする
docker compose down                        # 停止する
```

## 2-B. Windows PC で動かす

### 1) 実行ファイルを用意する

GitHub のリポジトリの「Actions」→「nas-backup」→ 最新の実行結果を開き、下の「Artifacts」にある `nas-backup-binaries` をダウンロードして展開します。
中の `nas-backup-windows-amd64.exe` を使います（例: `C:\nas-backup\` に置く）。

> Go をインストール済みなら `nas-backup` フォルダで `make dist` を実行しても作れます。

### 2) LS720D に一度接続しておく

エクスプローラーのアドレス欄に `\\192.168.1.50\share` と入力して開きます。ユーザー名とパスワードを聞かれたら入力し、「資格情報を記憶する」にチェックを入れます。

### 3) 起動用ファイルを用意する

[`deploy/ls720d/start-windows.bat`](../deploy/ls720d/start-windows.bat) を exe と同じフォルダにコピーし、メモ帳で開いて `BACKUP_DIR` を書き換えます。

```bat
set BACKUP_DIR=\\192.168.1.50\share\SmartphoneBackup
```

### 4) 起動する

`start-windows.bat` をダブルクリックします。
初めて起動したときに「Windows セキュリティの重要な警告」が出たら、**「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」** を押します。

画面に表示された `http://192.168.1.xx:8080` をスマホのブラウザで開きます。使い終わったら黒い画面（コマンドプロンプト）を閉じれば停止します。

### PC の起動時に自動で起動したい場合

`Win + R` で `shell:startup` を開き、`start-windows.bat` のショートカットを置きます。

> PC がスリープすると使えなくなります。バックアップ中はスリープしないよう、Windows の電源設定を確認してください。

## スマホからの使い方

1. スマホを家の Wi-Fi につなぎ、`http://<Raspberry Pi または PC の IP>:8080` を開く
2. 「写真・動画を選ぶ」→ ファイルを選ぶ →「バックアップ開始」
3. ホーム画面に追加しておくと、次からはアイコンをタップするだけで開けます

LS720D には次のように保存されます。

```
\\192.168.1.50\share\SmartphoneBackup\
├── papa\2026\2026-11\IMG_0001.HEIC
├── mama\2026\2026-10\IMG_0456.MOV
└── .nasbackup\      ← アプリの管理用フォルダ（消さないでください）
```

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| `保存先フォルダが見つかりません` | 1-4 の `SmartphoneBackup` フォルダを作ったか、パスの綴り（`.env` の `NAS_SHARE` / bat の `BACKUP_DIR`）を確認。LS720D の電源・LAN ケーブルも確認 |
| `mount error(13): Permission denied` | `.env` のユーザー名・パスワードが違うか、そのユーザーに共有フォルダへの書き込み権限がない |
| `mount error(2): No such file or directory` | `NAS_SHARE` の共有フォルダ名またはフォルダ名が違う |
| `mount error(95): Operation not supported` / `mount error(112)` | SMB のバージョンが合っていない。`.env` の `NAS_SMB_VERSION` を `2.1` → `2.0` の順に変えて `docker compose up -d` |
| `.env` を直したのに接続設定が変わらない | Docker のボリュームに古い設定が残っています。`docker compose down -v` の後に `docker compose up -d --build`（`-v` で消えるのは接続設定だけで、NAS 上のファイルは消えません） |
| スマホでページが開けない | スマホが家の Wi-Fi につながっているか、URL が Raspberry Pi / PC の IP アドレスになっているか（LS720D の IP ではありません）、Windows のファイアウォールで許可したか |
| 送信が「再接続を待っています…」のまま進まない | LS720D がスリープ中・再起動中でないか確認。復帰すれば自動で続きから再開します |
| LS720D のごみ箱にファイルが溜まる | 重複していたファイルや、途中で止まったまま 7 日経った送信途中ファイルを削除したものです。気になる場合は、保存先の共有フォルダのごみ箱設定を見直すか、ごみ箱を空にしてください |
