# 書き込みと調整の手順

コマンドは OctoPrint の「ターミナル」タブから送る。`M500` を送るまで設定は保存されない。

> [!warning] 初めての G28 / G29 の前に
> BLTouch のずれも Z オフセットもまだ合っていないので、ノズルがベッドに当たる恐れがある。
> **いつでも電源を切れるようにしておく。**

## 0. 今の設定を控える（戻せるように）

1. OctoPrint のターミナルで `M503` を送り、出てきた内容をすべてコピーしてテキストで保存する
2. 今のファーム（`firmware-*.bin`）が手元にあれば残しておく

## 1. 書き込み

1. GitHub のビルド結果の「Artifacts」から zip をダウンロードし、中の `firmware.bin` を
   **前回と違う名前**（例：`fw-20261128.bin`）にして SD カードの一番上に置く
   （4.2.7 は前回と同じ名前だと書き換えない）
2. 電源を切り、SD を挿して電源を入れる。30 秒ほど待って液晶が映れば完了
   - 映らない・文字が化ける → `RET6_12864_LCD` を `VET6_12864_LCD` に変えてビルドし直す
3. `M502` → `M500`（新しいファームの初期値で保存し直す）

## 2. 動く向きの確認

1. 液晶の「Move Axis」で X と Y を 10mm 動かし、向きが正しいか見る
2. Z を +10mm 動かし、**上がる**か見る
3. ノズルを 200℃ にして E を 10mm 送り、**フィラメントが出る**か見る
4. 逆の軸があれば教えてください（設定を 1 行変えてビルドし直します）

## 3. BLTouch の確認とずれの測定

1. `M280 P0 S10`（ピンが出る）→ `M280 P0 S90`（ピンが戻る）で動きを確認
2. ノギスで **ノズル先端の中心 → BLTouch のピンの中心** を測る
   - ピンがノズルより**左**なら X はマイナス、**手前**ならY はマイナス
3. `M851 X<測ったX> Y<測ったY>` → `M500`
4. `G28` で原点を取る（Z はベッド中央で BLTouch が当たる）

## 4. 原点の再現性を測る（原点ずれの切り分け）

```
G28
M48 P10 X110 Y110 V2
```

最後に出る `Standard Deviation` を見る。

| 標準偏差 | 判断 |
|---|---|
| 0.01 mm 以下 | 良好 |
| 0.01〜0.02 mm | 許容。BLTouch の固定ネジを確認 |
| 0.02 mm 超 | 機械側を疑う：LM ガイドとリードスクリューのこじれ、カップリング、BLTouch のぐらつき |

## 5. PID 調整

```
M303 E0 S210 C8 U1
M303 E-1 S60 C8 U1
M500
```

## 6. ベッドの四隅を合わせる

ベッドを 60℃ にして、液晶の「Bed Tramming」で四隅を紙 1 枚の隙間に合わせる。

## 7. Z オフセット

1. ベッド 60℃、ノズル 150℃ にする
2. 液晶の「Configuration → Advanced → Probe Offsets → Z Probe Wizard」で、紙 1 枚が軽く引っかかる高さに合わせる
3. `M500`

## 8. メッシュを取る

ベッド 60℃ のまま:

```
G28
G29 P1        ; BLTouch で自動測定（届かない点は残る）
G29 P3        ; 残った点を埋める
G29 S0        ; スロット 0 に保存（開始Gコードが読み込む）
G29 A
M500
```

## 9. 1 層目の確認

```
G26 B60 H200
```

格子模様が均一に潰れていれば完了。薄い・浮く・ちぎれる場合は、印刷中に液晶のノブを
**ダブルクリック**してベビーステップで Z を調整する（0.01mm 刻み）。その値はそのまま
Z オフセットになるので、終わったら `M500`。

## 10. E ステップの微調整

1. ノズル 200℃、押出機の入口から 120 mm の位置に印を付ける
2. `M83` → `G1 E100 F100`
3. 入口から印までの残りを測る（20 mm なら正確）
4. 新しい値 = 424.9 × 100 ÷ (120 − 残り) → `M92 E<新しい値>` → `M500`

## スライサーに入れるもの

- 開始Gコード：`gcode/start.gcode`（PrusaSlicer / OrcaSlicer 用。相対 E の設定で使う）
- 終了Gコード：`gcode/end.gcode`
- OctoPrint「設定 → GCODEスクリプト → 印刷ジョブがキャンセルされた後」：`gcode/octoprint_after_cancel.gcode`
