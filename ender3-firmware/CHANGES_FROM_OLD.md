# 以前の設定からの変更点

比較元：GitHub の `claude/ecstatic-dirac-X5bAn` ブランチ（2026-06-21）の `MarlinFirmware/Marlin/Configuration*.h`。
いまプリンタに入っている版（2026-08-16 に PC でビルドした `E3PS-1.0.0`）はこれより新しく、
Sprite 用の値などがすでに入っている可能性がある。

使っていない機能のブロック（TMC の UART 用電流、Chameleon など）の値の違いは、動作に関係しないので省いた。

## 土台

| | 以前 | 新しい版 |
|---|---|---|
| Marlin | 2.1.3 系（Creality の例をもとに継ぎ足し） | **公式 2.1.3 安定版の素の設定**に、必要な変更だけを当てた |

## ハードに合わせて直したもの

| 設定 | 以前 | 新しい版 | 理由 |
|---|---|---|---|
| E ステップ | 93 | **424.9** | 純正押出機の値のままだった。Sprite Extruder Pro の値に |
| 押出の向き `INVERT_E0_DIR` | false | **true** | Sprite はダイレクトドライブで逆回転 |
| 造形範囲 | 235 × 235 × 250、X は +10 はみ出し可 | **220 × 220 × 245** | 実測値に |
| BLTouch のずれ | X −45 / Y −5 / Z −1.2（独自マクロ） | X −44 / Y −10 / Z 0（仮） | どちらも未実測。書き込み後に測って `M851` で保存 |
| メッシュの範囲 | 手書き（MESH_MIN/MAX、左右前後の余白を個別指定） | Marlin が BLTouch のずれから自動計算 | 手書きの範囲とずれが食い違うと、端の点がずれる |
| メッシュの点数 | 3 × 3 | **5 × 5** | 3 × 3 では 1 層目の傾きを拾いきれない |
| 名前 | "Ender-3 Pro V1.5 (4.2.7)" | "Ender-3 Pro Sprite" | |

## 原点出し・1 層目のために変えたもの

| 設定 | 以前 | 新しい版 | 理由 |
|---|---|---|---|
| 2 回目のプローブ速度 | 1 回目の 1/2 | **1/4** | ゆっくり当てて原点のばらつきを減らす |
| プローブ間の持ち上げ | 展開 10 / 点間 5 / 2 回目前 5 mm | 5 / 3 / 2 mm | 速くなる。BLTouch には十分な高さ |
| プローブ誤差の許容 | 10 mm | 3 mm | 異常な値を早めに止める |
| ベビーステップ | 0.05 mm / クリック | **0.01 mm / クリック** | 1 層目を細かく詰められる |
| 四隅合わせ `LCD_BED_TRAMMING` | なし | **あり** | 液晶から四隅のネジ調整 |
| ベッド温度の安定待ち | 0 秒 | 5 秒 | 温度が落ち着いてから原点を取る |
| 開始Gコード | （スライサー任せ） | ベッドを温め切ってから原点 → メッシュ読込 | 新規。`gcode/start.gcode` |

## OctoPrint のために入れたもの

| 設定 | 以前 | 新しい版 |
|---|---|---|
| `HOST_ACTION_COMMANDS` / `HOST_PROMPT_SUPPORT` | なし（OctoPrint が接続時に警告） | **あり**。液晶での一時停止・中止を OctoPrint が認識 |

## 外したもの

| 設定 | 理由 |
|---|---|
| `FILAMENT_RUNOUT_SENSOR` | **センサーが付いていない**。誤検知で止まる原因 |
| `XY_AFTER_HOMING` / `Z_AFTER_HOMING` / `Z_AFTER_PROBING` / `HOMING_BACKOFF_POST_MM` | ホーム後に勝手に動くと、原点が合っているか確かめにくい |
| `QUICK_HOME` | X と Y を同時に斜めに動かしてホームする機能。精度には関係しない |
| `EEPROM_INIT_NOW` | 書き込むたびに保存値（Z オフセット・メッシュ）が消える |
| カスタム起動画面・ステータス画面、`STATUS_MESSAGE_SCROLLING`、`LCD_INFO_MENU`、`MEDIA_MENU_AT_TOP`、`MESH_EDIT_GFX_OVERLAY` | 画面の見た目だけ |
| `M114_DETAIL`、`RX_BUFFER_MONITOR`、`GCODE_CASE_INSENSITIVE`、`UTF_FILENAME_SUPPORT`、SD のソート | デバッグ用・便利機能。精度に関係しない |
| 押出の最大長 800 mm → 200 mm | ボーデン用の長さ。ダイレクトドライブでは不要 |
| フィラメント交換の抜き出し 600 mm → 80 mm | 同上 |
| 予熱メニュー 2 の "ABS" → "PETG"、ファン 255 → 0 | 使う材料に合わせた |

## そのまま引き継いだもの

基板 4.2.7、TMC2208 スタンドアロン、USB 115200 bps、BLTouch で Z 原点（ベッド中央）、UBL、
G28 後のメッシュ復帰、2 回プローブ、Z オフセットウィザード、ベビーステップの Z オフセット連動、
M48、G26、M600、EEPROM 保存、ノブの送り（2 クリック）とノイズフィルター、
モーター解放後の再ホーム、SD の読み直し、PID 初期値（21.73 / 1.54 / 76.55、書き込み後に `M303` で取り直す）。
